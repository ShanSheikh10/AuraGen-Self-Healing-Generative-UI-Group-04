# AuraGen-Self-Healing-Generative-UI-Group-04

Self-healing Generative UI that detects user interaction friction and dynamically adapts complex interfaces using LLMs, WebSockets, and React.

## Overview

AuraGen is designed to observe real-time user interaction friction, communicate telemetry through WebSockets, and dynamically re-generate or adjust UI components using Large Language Models (LLMs) and React.

### Core Stack

- **Frontend**: React
- **Real-Time Communication**: WebSockets
- **Intelligence**: LLM-driven UI adaptation engine
